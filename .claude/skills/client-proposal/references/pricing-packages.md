# Pricing Packages — IN-FLU-ENTIAL LLC defaults

These are STARTING numbers pulled from James's real project history. Always confirm
the final figure with James before a proposal goes out. Adjust up for rush timelines,
heavy custom features, or clients with funding; never discount below floor without
James saying so explicitly.

## 1. Flat HTML One-Pager — "Launch Page"
- **Default: $1,200** (floor $900)
- Single index.html, Tailwind CDN, mobile-first, contact/order form, deployed to Vercel
- Reference builds: EGOFF Essentials, A&B Supply
- Timeline: 1 week
- Deliverables for scope table: custom single-page design, brand palette + typography,
  product/service showcase, contact or order capture, Vercel deploy + domain connect,
  owner self-edit guide

## 2. Next.js Business Site — "Full Presence"
- **Default: $3,000** (floor $2,500) — matches the public price on in-flu-ential.vercel.app
- Next.js 16 App Router, Tailwind, multi-page, SEO metadata, deployed to Vercel
- Reference builds: MVC Creations, Donald Markowitz, Graham Hill
- Timeline: 2–3 weeks
- Deliverables: 4–6 page custom site, design system matched to brand, gallery/portfolio,
  contact + newsletter capture (Resend), SEO + OG metadata, Vercel deploy + custom
  domain, owner self-edit guide

## 3. Booking + Payments Site — "Open for Business"
- **Default: $5,000** (floor $4,000)
- Package 2 PLUS the full booking-system stack: Stripe Checkout, Turso DB, Resend
  confirmation emails, .ics calendar invites, /admin/bookings panel, discount codes
- Reference builds: Epoch Skin, Jade the Gem, MCS, Flu-Haul
- Timeline: 3–4 weeks
- Deliverables: everything in Full Presence, plus online booking with live payment,
  automated email confirmations + calendar invites, admin booking dashboard,
  discount-code support, webhook-verified payments

## 4. Merch / E-commerce Add-on
- **Default: +$1,500** on top of any site package
- Stripe + Printify (or Shopify Storefront API) product catalog, cart, checkout,
  fulfillment webhook, order confirmation emails
- Reference builds: Jade the Gem merch, MVC Creations (Stripe + Turso shop)

## 5. Social Clip Production Retainer — "Always Posting"
- **Default: $750/mo starter (12 clips/mo) · $1,500/mo growth (30 clips/mo + scheduling)**
- Powered by clip-pipeline + social-scheduler (Ayrshare): cutting, 9:16 reframe,
  captions/titles, scheduled posting across platforms
- Month-to-month, 30-day notice; first month due to begin
- Pair with client-report: monthly branded performance recap included at growth tier

## 6. Campaign / Creative Direction — "The Push"
- **Default: $5,000 per campaign** (reference: Graham Hill "The Drummer Steps Forward")
- Brand/campaign strategy, content plan, launch assets, 30-day execution window
- Larger engagements: $12,500 strategy + execution, $25,000+ full creative direction
  (custom quote — the IN-FLU-ENTIAL site no longer lists these tiers)
